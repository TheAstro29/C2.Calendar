# C2 Calendar

ปฏิทินและระบบจัดการงานภายในของ **C2 Tech Company Limited (บริษัท ซีทูเทค จำกัด)** ใช้วางแผนงานของทีม ติดตามความคืบหน้า และแจ้งเตือนผู้เกี่ยวข้อง ใช้งานได้ทั้งบนคอมพิวเตอร์และมือถือ (ติดตั้งเป็นแอปบนหน้าจอโฮมได้)

> ระบบนี้ใช้ภายในองค์กร ต้องล็อกอินด้วยบัญชีที่ผู้ดูแลสร้างให้

เว็บไซต์ที่ใช้งานจริง: https://theastro29.github.io/C2.Calendar/

## ฟีเจอร์หลัก

- **ปฏิทินหลัก** — ดูงานทั้งทีมเป็นรายเดือน/สัปดาห์/รายการ แยกสีตามประเภทงาน กรองตามผู้ปฏิบัติงานหรือประเภท และแสดงวันหยุดองค์กรบนปฏิทิน
- **สร้าง/แก้ไขงาน** — กำหนดชื่อ ประเภท ช่วงเวลา (ทั้งวันหรือระบุเวลา) ผู้ปฏิบัติงาน รายละเอียดแบบ rich text เช็กลิสต์ ไฟล์แนบ และเวลาแจ้งเตือนล่วงหน้า
- **ปักหมุดสถานที่บนแผนที่** — ค้นหาสถานที่หรือคลิกบนแผนที่ Google Maps เพื่อปักหมุด หมุดจะยังอยู่เมื่อแก้ไขงานหรือเปลี่ยนวัน และกดแผนที่ในหน้ารายละเอียดงานเพื่อเปิดนำทางไปยังหมุดได้ทันที
- **งานรอกำหนดวัน (To-Do List)** — เก็บงานที่ยังไม่ระบุวัน แล้วกำหนดวันภายหลัง
- **Task ของฉัน** — งานส่วนตัวของแต่ละคน พร้อมสถานะ กำหนดส่ง และการเตือนเมื่อใกล้ครบกำหนด
- **ขอเปลี่ยนวัน / ขอแก้ไข / ขอลบงาน** — ผู้ใช้ทั่วไปส่งคำขอ ผู้ดูแลอนุมัติหรือปฏิเสธ งานจริงเปลี่ยนเมื่ออนุมัติแล้วเท่านั้น
- **ความคิดเห็นในงาน** — คอมเมนต์ แก้ไข และลบได้ทั้งงานของทีมและงานส่วนตัว
- **การแจ้งเตือน** — แจ้งเตือนในแอป (กระดิ่ง) และ Push Notification เตือนงานที่ใกล้ถึงเวลา ตั้งค่าเปิด/ปิดตามประเภทได้
- **Dashboard และ Task Board** — สรุปงานภาพรวมขององค์กร สถานะ ความสำคัญ ภาระงานรายบุคคล งานใกล้/เกินกำหนด และแท็ก
- **รายงาน** — ส่งออกเป็นไฟล์ Excel หรือพิมพ์รายงาน (Admin / CEO)
- **จัดการบัญชีและวันหยุด** (Admin) — สร้าง แก้ไข ปิดใช้งานบัญชี รีเซ็ตรหัสผ่าน และเพิ่ม/ลบวันหยุดองค์กร
- โหมดสว่าง/มืด และปรับหน้าจอให้เหมาะกับมือถือ

## เทคโนโลยี

| ส่วน | ใช้อะไร |
|---|---|
| Frontend | HTML / CSS / JavaScript ล้วน (ไม่มี build step) โฮสต์บน GitHub Pages |
| Backend | Firebase Cloud Functions (callable) |
| ฐานข้อมูล | Cloud Firestore |
| ไฟล์แนบ | Firebase Storage |
| แจ้งเตือน | Firebase Cloud Messaging + Cloud Functions ที่ทำงานตามเวลา (เช็กงานใกล้ถึงเวลาทุก 5 นาที) |
| แผนที่ | Google Maps JavaScript API (Places, Geocoding) |
| ส่งออกรายงาน | SheetJS (xlsx) |

## โครงสร้างโปรเจกต์

```
C2-Calendar/                ← frontend (repo นี้)
├─ index.html               โครงหน้าเว็บและ modal ทั้งหมด
├─ app.js                   ตรรกะทั้งหมดของแอป
├─ style.css                สไตล์ทั้งหมด
├─ firebase-messaging-sw.js Service Worker สำหรับ Push Notification
├─ manifest.json            ติดตั้งเป็นแอป (PWA)
└─ icons/                   ไอคอนแอป

c2-calendar-firebase/       ← backend (แยกโฟลเดอร์/repo)
├─ functions/index.js       Cloud Functions
├─ firestore.rules          กฎความปลอดภัยของ Firestore
└─ storage.rules            กฎความปลอดภัยของ Storage
```

## การอัปเดตและ Deploy

**Frontend** (`index.html`, `app.js`, `style.css`)
แก้ไฟล์แล้ว commit/push ขึ้น GitHub ระบบ GitHub Pages จะเผยแพร่ให้เอง ไม่ต้อง build เมื่อแก้ไฟล์ แนะนำให้เปลี่ยนเลขเวอร์ชันท้าย `app.js?v=...` และ `style.css?v=...` ใน `index.html` เพื่อให้ผู้ใช้ได้ไฟล์ใหม่ทันที (ถ้ายังเห็นของเดิม ให้รีเฟรชแบบล้างแคช `Ctrl + Shift + R`)

**Backend** (Cloud Functions)
แก้ที่ `functions/index.js` แล้ว deploy จากโฟลเดอร์ backend:

```bash
firebase deploy --only functions
```

การแก้ไฟล์เฉยๆ ไม่มีผลกับระบบจริงจนกว่าจะ deploy

## การรันทดสอบในเครื่อง

เปิด `index.html` ผ่านเซิร์ฟเวอร์ภายในเครื่อง (เช่น `npx serve` หรือ Live Server ใน VS Code) ระบบจะเชื่อมกับโปรเจกต์ Firebase จริง จึงควรทดสอบด้วยบัญชีทดสอบและระวังไม่ให้ข้อมูลจริงเสียหาย

## สิทธิ์การใช้งาน

| บทบาท | ทำอะไรได้ |
|---|---|
| Staff (ผู้ใช้ทั่วไป) | ดูปฏิทิน จัดการงานของตัวเอง ส่งคำขอเปลี่ยนวัน/แก้ไข/ลบงาน |
| CEO | ดู Dashboard และส่งออกรายงานภาพรวมองค์กร |
| Admin | ทุกอย่างข้างต้น + อนุมัติคำขอ จัดการบัญชีผู้ใช้และวันหยุดองค์กร |

## การตั้งค่าที่ต้องมี

- **Google Maps API key** — ตั้งค่าในตัวแปร `GOOGLE_MAPS_API_KEY` ที่ต้นไฟล์ `app.js` ควรจำกัดคีย์ให้ใช้ได้เฉพาะโดเมนของเว็บนี้ในหน้า Google Cloud Console
- **FCM VAPID key** — ตัวแปร `FCM_VAPID_KEY` ใน `app.js` สำหรับ Push Notification ถ้าไม่ตั้งค่า แจ้งเตือนในแอปยังทำงานตามปกติ
